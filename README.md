# База данных компьютерного клуба

## Описание проекта

Проект посвящён проектированию и разработке реляционной базы данных компьютерного клуба с использованием PostgreSQL и pgAdmin 4.

## Цель проекта

Создать базу данных для хранения информации о клиентах, компьютерах, тарифах, игровых сеансах и платежах.

## Структура базы данных

- `clients` — сведения о клиентах.
- `computers` — компьютеры клуба и их состояние.
- `tariffs` — тарифы и стоимость часа.
- `sessions` — игровые сеансы клиентов.
- `payments` — информация об оплатах.

## Используемые технологии

- PostgreSQL
- pgAdmin 4
- SQL

## Результат

Разработана структура базы данных компьютерного клуба с таблицами, связями, ограничениями целостности и SQL-запросами для получения информации.
